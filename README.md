# Disseration
Evaluting Traditional and Deep learning based Slam
This project aims to conduct a literature review and implementation of traditional visual odometry and deep learning-based odometry techniques for SLAM. The objectives of this project are as follows:
Aims and Objectives

    Literature Review and Implementation
        Research and implement traditional visual odometry, ORB-SLAM2, and test it on the KITTI dataset
        Research and implement deep learning-based visual odometry, DeepVO, and test it on the KITTI dataset
    Evaluation and Comparison
        Perform a trajectory-based evaluation on deep learning-based odometry and traditional odometry methods on the KITTI dataset
        Identify and define error metrics for evaluating the performance of odometry methods, such as absolute trajectory error (ATE), relative pose error (RPE).
        Analyze and compare the error metrics obtained from the evaluation of DeepVO and ORB-SLAM2 on the KITTI dataset4
        .
    Semantic Segmentation
        Implement the Deeplab v3+ model for semantic segmentation.
        Develop a method for masking dynamic objects and process it to the visual odometry.
        Test the impact of masked images on ORBSLAM2 for trajectory estimation.
